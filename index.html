            왜 둘 다 index.html일까요?
            웹 서버는 주소가 폴더(저장소 이름)로 끝나면 그 안의 index.html을 자동으로 엽니다. 그래서 …github.io/저장소이름/만으로 앱이 열립니다. 다른 이름이면 주소 끝에 파일 이름까지 붙여야 하고, 빠뜨리면 404가 납니다.
            
    
            저장 방법
            전체 복사(Ctrl+A → Ctrl+C) → 메모장에 붙여 넣기 → 다른 이름으로 저장 → 해당 앱 폴더 선택 → 파일 형식 모든 파일 → 인코딩 UTF-8. 맥은 포맷 › 일반 텍스트로 만들기를 먼저.
            
  
            
  
            이름이 index.html.txt처럼 저장되는 실수가 가장 흔합니다. 한글이 깨지면 인코딩이 UTF-8이 아닌 것입니다.

                            피드백 자리에 '키가 설정되지 않았습니다'스크립트 속성 이름이 정확히 GEMINI_API_KEY인지 확인
                            
    
                            '피드백 생성 실패: 400·403'키 값이 정확한지, 키가 삭제되지 않았는지 확인 → testSetup으로 다시 시험
                            
    
                            '피드백 생성 실패: 429'무료 사용량 초과. 잠시 뒤 다시 시도하거나 동시에 제출하는 인원을 나눔
                            
  
                            

                            

                            



                            

                            
  
                            6차시 · Supabase 연동 앱 & 성과 공유

                            테이블 SQL접속 정보(.env)연동 프롬프트Vercel 환경변수막힐 때수업 적용 계획
                            
  
                              

                              


                              
  
                              테이블 만들기 SQL
                              
  
                              만들 기능을 고르고 SQL Editor에 붙여 넣어 Run 하세요. 학생은 읽기와 쓰기만 할 수 있고 수정·삭제는 못 하도록 보안 규칙(RLS)과 접근 허용(GRANT)이 함께 들어 있습니다.
                              
  
                              상담 기록 등 민감한 업무 데이터는 Supabase에 올리지 않습니다. 학생과 함께 쓰는 공개 데이터만 다룹니다.
                              
  
                              
    
                              
      
                              
      
                              
    
                              
  
                              
  
                              SQL Editor에 붙여 넣기
                              
  
                              
  
                              GRANT 줄을 빼면 "테이블은 있는데 앱에서 안 보이는" 문제가 생깁니다. 지금 Supabase는 새 테이블을 자동으로 공개하지 않기 때문입니다.
                              

                              


                              
  
                              접속 정보(.env) 만들기
                              
  
                              Project Settings → API Keys에서 Project URL과 Publishable key(sb_publishable_로 시작)를 복사해 넣으세요. Secret key는 절대 쓰지 않습니다.
                              
  
                              
    
                              
      
                              
      
                              
    
                              
    
                              .env 파일 내용
                              
    
                              Publishable key는 브라우저에 공개되는 것을 전제로 한 키라서, 위 SQL의 보안 규칙(RLS)이 데이터를 지켜 줍니다.

                              Vercel에 환경변수 등록
                              
  
                              .env 파일은 GitHub에 올라가지 않으므로, 배포된 앱이 쓰도록 Vercel에도 같은 값을 넣어야 합니다.
                              
  
                              단계할 일
                              
    
                              1. 위치Vercel 프로젝트 → Settings → Environment Variables
                              
    
                              2. 추가VITE_SUPABASE_URL, VITE_SUPABASE_PUBLISHABLE_KEY 두 개를 .env와 같은 값으로 추가
                              
    
                              3. 다시 배포Deployments → 최신 배포 ⋯ → Redeploy (환경변수는 새 배포부터 적용)
                              
    
                              4. 확인vercel.app 주소를 두 기기에서 열고 한쪽에서 쓴 글이 다른 쪽에 바로 나타나는지 확인
                              
  
                              

                              


                              
  
                              막힐 때
                              
  
                              이런 상황이면이렇게 해 보세요
                              
    
                              permission denied 오류SQL의 GRANT 줄이 실행됐는지 확인 → SQL을 다시 실행
                              
    
                              글이 저장은 되는데 실시간으로 안 떠요SQL 마지막 줄(supabase_realtime 추가)이 실행됐는지 확인, 새로고침해서 보이면 실시간 구독 문제 → 에이전트에게 실시간 구독 점검 요청
                              
    
                              내 컴퓨터에선 되는데 배포 후엔 안 돼요Vercel 환경변수 이름이 VITE_로 시작하는지 확인 → Redeploy
                              
    
                              프로젝트가 멈춰(Paused) 있어요무료 플랜은 오래 안 쓰면 일시정지됨 → 대시보드에서 Restore, 수업 전날 꼭 확인
